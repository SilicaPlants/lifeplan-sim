# LifePlanSim

ライフプランを 1 年きざみでシミュレーションする Web アプリです。

1. **基本情報**（家族構成・年収・家賃・生活費・貯蓄額）を入力
2. **フローチャート形式の質問**（転職・子ども・住宅購入・引越し）に回答
3. **結果**として貯蓄残高のグラフとワンポイントアドバイスを表示

## 使い方

```bash
npm install
npm run dev
```

http://localhost:5173 を開きます。

| コマンド | 出力 | 用途 |
| --- | --- | --- |
| `npm run dev` | — | 開発用サーバー |
| `npm run build` | `dist/` | 公開用の静的サイト（全機能・オフラインでも動作） |
| `npm run build:single` | `dist-single/index.html` | 1 枚の HTML にまとめたもの（ファイルを渡すだけで動く） |
| `npm run build:artifact` | `dist-single/artifact.html` | claude.ai の Artifact に貼るための断片 |

## 公開する

サーバー側の処理は一切なく、入力はすべてブラウザの localStorage に保存されるため、**静的ホスティングにそのまま置けます**。

### GitHub Pages

`.github/workflows/deploy.yml` を同梱しています。リポジトリを作って push し、GitHub の Settings → Pages で Source を「GitHub Actions」にすれば、`main` への push ごとに自動で公開されます。

```bash
git init && git add -A && git commit -m "LifePlanSim"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
git push -u origin main
```

サブパスに置かれるため、ワークフロー内で `VITE_BASE=/<リポジトリ名>/` を渡してビルドします。手元で同じものを確認するには `VITE_BASE=/<リポジトリ名>/ npm run build`。

### Netlify / Vercel / Cloudflare Pages

いずれもビルドコマンド `npm run build`、公開ディレクトリ `dist` を指定するだけです。ビルド済みの `dist/` フォルダをドラッグ＆ドロップでアップロードすることもできます。

### 1 枚の HTML として配る

`npm run build:single` で作られる `dist-single/index.html` は、これ 1 つで動きます。社内の共有フォルダに置く、メールに添付する、といった配り方もできます。

## 制限

- 入力内容はブラウザごとに保存されます（サーバーには送られません）。端末をまたぐ場合はプラン管理の「ファイルに書き出す／読み込む」を使ってください
- claude.ai の Artifact として公開共有した場合、ブラウザのダウンロードが許可されないため Excel と画像の保存が使えません（画面上でその旨を表示します）。すべての機能を使うには上記の静的ホスティングに置いてください

入力中の内容はブラウザの localStorage に自動保存され、次回アクセス時に復元されます。名前を付けたプランの保存については「プランの保存」を参照してください。

## 画面の流れ

| 画面 | 内容 |
| --- | --- |
| 基本情報 | 年齢・配偶者・子ども・年収・住まい（実家／賃貸／持ち家。持ち家ならローンの残り年数と維持費）・大人の生活費、および資産（現金・投資・積立額・預金金利・投資利回り）。詳細設定で昇給率、退職年齢、退職金、年金額を調整できます |
| 質問 | 子ども → 住宅 → 引越し → 働き方 → 大型出費 → 老後 の順に回答します。左のフロー図は現在地と回答内容を表示し、**クリックで任意の質問や結果へ移動**できます。住宅を購入する回答をすると引越しの質問は自動的にスキップされます |
| └ 引越し | 引越しを何回でも登録できます。住宅購入を予定していても、購入までのあいだの賃貸を設定できます |
| └ 働き方 | 転職・育休・時短勤務・専業主婦（主夫）など、本人・配偶者の収入が変わるタイミングを何件でも登録できます |
| └ 子ども | これから生まれる人数と、**お子さんごとの誕生時期**（第1子は3年後、第2子は5年後…）に加えて、**最終学歴**と**進学段階ごとの公立／私立**を選べます。教育費と養育費の金額も調整できます |
| └ 大型出費 | 結婚式・車の購入・住宅リフォーム・旅行など、まとまった支出を登録できます。車の買い替えのように繰り返す出費にも対応します |
| └ 資産 | 積立額の変更（何回でも）、投資資産の取り崩し方（出口戦略）、積立をやめる年齢・取り崩し開始年齢・取り崩し後の利回りを設定します |
| 結果 | 総資産の推移（保存プランとの重ね合わせ比較つき）、現金と投資の内訳、年間の収入と支出、アドバイス、年次の内訳表。画面上部と下部に「最初からやり直す／この結果を保存／条件を変えて試す／Excel をダウンロード」を配置しています |

グラフはマウス移動でクロスヘアとツールチップが出ます。フォーカスしてから左右キーでも年を移動できます。

グラフにカーソルを載せると右上に「**画像としてコピー**」が出ます。押すと PNG（2 倍解像度・背景つき）にしてクリップボードへコピーするので、資料やチャットにそのまま貼り付けられます。クリップボードが使えない環境では画像ファイルとして保存します。CSS 変数で指定している色は書き出し時に実際の色へ解決するため、画面と同じ見た目になります。

## プランの保存

ヘッダーの「プランを保存」または結果画面の「この結果を保存」から、いまの条件に名前を付けて保存できます。件数の上限はありません。

- **保存** … 家族構成や住宅の予定から名前の候補（例: `32歳・夫婦・子1人・住宅購入`）が自動で入ります。読み込み中のプランがあるときは「上書き」も選べます
- **一覧** … 各プランの条件の要約に加えて、**95歳時点の総資産**と**資金ショートの有無**を並べて表示するので、条件を変えた案をその場で見比べられます
- **結果画面から直接開く** … 結果画面の上部にある「**保存したプランを開く**」から、保存済みプランを一覧で選んですぐ切り替えられます。各行に 95 歳時点の総資産と資金ショートの年が出るので、開く前に見当がつきます
- **比較** … 総資産グラフの上に並ぶプラン名を押すと、**同じグラフに重ねて**描画されます（最大 3 件。いまの条件は実線、比較プランは破線）。下の比較表に最終年の総資産・退職時の総資産・最も少ない残高・資金ショートの年が並び、最終年の総資産にはいまの条件との差額（+/−）が付きます
- **開く / 複製 / 名前変更 / 削除** … 「開く」を押すとその条件で結果画面が開きます。名前は一覧上で直接編集できます
- **ファイルに書き出す / 読み込む** … 全プランを JSON ファイルとして保存し、別の端末やバックアップから復元できます

保存先はブラウザの localStorage（キー `lifeplansim.plans.v1`）です。読み込むファイルは外部由来のこともあるため、`storage.ts` の `parseImport` が 1 項目ずつ型を検査し、欠けている値や不正な値は既定値で補って取り込みます。

## 働き方・収入の変化

本人と配偶者それぞれについて、「何年後から年収がいくらになるか」を収入イベントとして登録します。転職・育休・時短勤務・専業主婦（主夫）・役職定年・定年後の再雇用など、収入が変わる出来事はすべてこの形で表せます。適用されるのはその年以降で、次のイベントが来るまで昇給率に沿って増えていきます。

- **区分「給与」** … 給与所得控除・社会保険料・所得税・住民税を差し引いて手取りを計算します。年収 0 は無収入（専業主婦・主夫、休職など）を意味します
- **区分「給付金」** … 育児休業給付金のように非課税・社会保険料免除の収入として扱い、手取り＝入力額とします。この期間は昇給もかかりません

登録した行は**入力順のまま並び**ます（時期を変えても行が動かないので編集しやすく、必要なときだけ「時期順に並べ替える」で整理できます）。各行の下には「2033年 · 本人37歳 · 配偶者36歳 · 第1子4歳」のように、西暦と家族それぞれの年齢が表示されます。

「配偶者の育休（2 年）」などのプリセットを押すと、育休（休業前賃金の約 60% を給付金として計上）と職場復帰の 2 件がまとめて登録されます。「役職定年（55 歳）」は、管理職手当がなくなって年収が 2〜3 割下がる想定で、**55 歳になる年に年収 75%** のイベントを入れます（時期も下げ幅も会社によって違うので、追加後に調整してください）。定年後の再雇用も同じ形で登録できます。プリセットで入れたあとに時期・金額・ラベルを自由に編集できます。同じ人・同じ年のイベントは、後から登録したものが優先されます。

## 生活費と養育費

```
生活費 = 大人の生活費（月額 × 12 × 退職後の比率） + Σ 各お子さんの養育費
```

- **大人の生活費** … 本人と配偶者の分だけを入力します（住居費・教育費・お子さんの分は含めません）。退職後は 85% に下がります
- **養育費** … お子さん 1 人あたりの年額を年齢帯ごとに設定します。学費とは別に、食費・衣類・医療費・生活用品・小遣い・レジャー費と、世帯人数が増えることによる光熱費・通信費の増加分を見込む金額です。現在いるお子さんも将来生まれるお子さんも同じ扱いで、人数分そのまま加算されます

### 進路の選び方

**最終学歴**（高校卒／大学卒／大学院卒）と、**幼稚園・小学校・中学校・高校・大学・大学院それぞれの公立／私立**を個別に選べます。最終学歴より先の段階はグレーアウトし、その年齢以降は教育費も養育費も計上しません（高校卒なら 17 歳、大学卒なら 21 歳、大学院卒なら 21 歳＋在学年数まで）。

よくある組み合わせはワンクリックで入ります： `すべて公立・大学卒` / `大学だけ私立`（既定） / `高校から私立` / `中学から私立` / `すべて私立` / `高校卒で就職`。押したあとに段階ごとの変更もできます。各行にはその段階で適用される年額が表示されます。

大学院卒を選ぶと在学年数（修士 2 年、博士まで 5 年など）を指定でき、22 歳の年に入学金 20 万円を加算します。既定の年額は国公立 70 万円・私立 110 万円です。

質問の「子ども」ステップには「教育費を調整する」と「養育費を調整する」の 2 つの折りたたみがあります。教育費は公立・私立それぞれ 6 学齢の年額を編集でき、いま選んでいる進路で実際に使われる項目には「適用中」と表示されます。養育費は 6 区分すべてを編集でき、1 人あたり 0〜21 歳の合計額がその場で表示されます。既定値から変えた項目には「変更中」と元の金額が表示され、「既定値に戻す」でいつでもまとめて戻せます（すべて既定値のときはボタンが無効になります）。Excel でも INPUT シートの「養育費（0〜2歳）〜（18〜21歳）」を書き換えれば再計算されます。

## 住まいと引越し

現在の住まいは**実家／賃貸／持ち家**から選べます。金額欄のラベルが「家に入れている金額」「家賃・住居費」「ローン返済額」に変わり、実家住まいで住居費 0〜3 万円、といった設定がそのまま表せます。

**持ち家**を選ぶと、さらに「**ローンの残り返済年数**」と「**維持費（月額）**」を入力できます。残り年数のあいだは返済額＋維持費がかかり、完済後は維持費だけになります（完済年はグラフにイベントとして表示されます）。すでに完済していれば残り年数を 0 にしてください。

引越しは**何回でも**登録でき、その年以降は最後に登録した引越し先の家賃が適用されます。住宅購入を予定していても引越しの質問は出るので、**実家 → 賃貸 → 持ち家**のような流れも表現できます（購入後は持ち家に切り替わります）。初期費用は敷金・礼金・引越し代の目安として、新しい家賃の指定した月数分（既定 4 か月）をその年に計上します。

## 大型出費

結婚式・車の購入・住宅のリフォーム・旅行などを、**時期・金額・繰り返し間隔・内容**の4項目で登録します。繰り返しを「7年ごと」にすると、その年から指定した年齢まで 7 年間隔で計上されます（「1回だけ」なら単発）。**「◯歳まで」**を指定すれば「車の買い替えは 65 歳まで」のように打ち切れます（0 なら期限なし）。入力欄には 95 歳までの発生回数と合計額が出るので、買い替えサイクルの生涯コストがその場で分かります。

**支払い元**も選べます。「現金から払う」（既定）に加えて「投資を取り崩す」を選ぶと、その年に必要額だけ投資資産を売却して充てます。住宅購入の頭金・諸費用にも同じ選択肢があります。

プリセットは結婚式・車の購入（7年ごと・75歳まで）・住宅リフォーム（住宅購入の 15 年後に自動設定）・家族旅行（3年ごと・80歳まで）・家電の買い替え（8年ごと）の 5 種類です。収入の変化と同じく行は入力順のまま並び、各行の下に西暦と家族それぞれの年齢が出ます。

グラフのイベント注釈では、繰り返す出費は初回だけラベルを表示します（毎回表示すると注釈で埋まるため）。各年の金額は結果画面の内訳表とツールチップで確認できます。

## 積立額の変更

基本情報で入れた毎月の積立額は、質問の「資産」ステップで**途中から変えられます**。「4年後に月2万へ（育休で減額）」「8年後に月12万へ（転職後に増額）」のように何回でも登録でき、その年以降は最後に登録した額が適用されます。グラフには変更した年がイベントとして表示されます。

積立額を変えても、その年に使える現金が足りなければ自動的に減額される点は変わりません。

## 物価上昇（インフレ）

**物価上昇率**を生活費・教育費・家賃・大型出費に反映します。**既定は 0%**（物価上昇を見込まず、いまの金額のまま試算する）で、基本情報の詳細設定から変更できます。

60 年を超える試算では影響が大きく、既定値のケースで 95 歳時点の総資産は 2 億 4,195 万円（0%）から 1 億 980 万円（1.5%）へと変わります。実質的な購買力で見たい場合は 1〜2% を設定してください。

物価に連動しないものは据え置きです。

| 連動する | 連動しない |
| --- | --- |
| 生活費・養育費・教育費・家賃・持ち家の維持費・大型出費・引越しの初期費用 | 住宅ローンの返済額（固定金利のため）・物件価格（購入時点の価格を入力する前提） |

**年金**はマクロ経済スライドを考慮し、物価上昇率から調整率（0.9%）を引いた率で増えます（＝実質は目減りします）。**退職金**は賃金水準に連動するものとして昇給率で増やします。

## 住宅ローン控除

住宅購入を選ぶと既定で適用されます。**年末残高（上限あり）× 控除率**が、その年の所得税と住民税（課税所得の 5%・上限 9.75 万円）の範囲で戻ります。控除期間・控除率・残高上限はすべて変更でき、既定は新築を想定した 13 年・0.7%・3,000 万円です（住宅の省エネ性能により 2,000〜5,000 万円）。

借入 4,000 万円のケースで 13 年間に 271 万円が戻る計算になります。年末残高は元利均等返済の式から各年ごとに求めており、Excel の「年末ローン残高」列で確認できます。

## iDeCo・企業型DC

基本情報の資産欄で**掛金（月額）**と**現在の残高**を設定できます。

- 掛金は**全額が所得控除**（小規模企業共済等掛金控除）になり、所得税・住民税が軽くなります
- 60 歳まで引き出せないため、それまでは投資資産とは別に運用し、**60 歳で投資資産に合流**します（現金が不足しても取り崩されません）
- 受け取り時の退職所得控除・公的年金等控除は考慮していません

既定値のケースに月 2.3 万円（会社員の上限の目安）を足すと、95 歳時点の総資産が 3,543 万円増えます。

## 老後の出口戦略

退職後に投資資産をどう現金化するかを 4 つから選べます。

| 戦略 | 動き | 向いている場面 |
| --- | --- | --- |
| 必要な分だけ取り崩す（既定） | 生活費が足りない年に不足分だけ売却 | 運用期間を最大化したい |
| 毎年決まった額 | 開始年齢から毎年同じ額を取り崩す | 生活設計を立てやすくしたい |
| 毎年決まった率 | 残高に対する一定割合を取り崩す（4% ルールなど） | 資産を枯渇させたくない |
| 全額を現金化 | 開始年齢の 1 年で全額を現金へ移す | 値動きのリスクを避けたい |

併せて **積立をやめる年齢**（既定 65 歳）、**取り崩しを始める年齢**（既定 65 歳）、**取り崩し開始後の利回り**（既定 3%。債券などへ移してリスクを下げる前提なら低めに）を設定します。取り崩し開始後は投資資産の利回りがこの値に切り替わります。

どの戦略でも、現金が足りなくなった年は不足分だけ追加で取り崩します（内訳表では「計画取崩額」と「不足補填の取崩額」を分けて計算しています）。取り崩した額は現金に入るため、使い切らなかった分は現金として残ります。

## 現金と投資を分けた資産計算

資産は「現金・預金」と「投資資産」に分け、それぞれに別の利回りを適用します。各年の処理は次の順序です。

1. 現金に預金金利、投資資産に想定利回りをかける
2. 年間収支（収入計 − 支出計）を現金に反映する
3. 「毎月の積立額 × 12」を現金から投資へ振り替える（その年に使える現金の範囲まで自動的に減額。現金がマイナスなら 0。積立をやめる年齢に達したら 0）
4. 「投資から払う」と指定した支出（大型出費・住宅の頭金）のぶんを取り崩して現金に移す
5. 出口戦略にもとづいて計画的に取り崩し、現金に移す
6. それでも現金が足りない年は、不足分だけ投資資産を追加で取り崩す
7. 投資も尽きると総資産がマイナス（資金ショート）になる

## Excel 出力

結果画面の「Excel をダウンロード」から、計算式入りの xlsx を書き出せます。

| シート | 内容 |
| --- | --- |
| はじめに | 使い方、表記ルール、計算の前提 |
| INPUT | 入力値と前提（黄色いセル）。給与所得控除・所得税の速算表、教育費テーブル、税率なども編集できます |
| 計算 | 1 年 1 行の明細。全セルが INPUT を参照する数式で、収入イベントの適用（直近の変更年・変更後の年収・非課税区分）、給与所得控除・社会保険料・所得税・住民税・教育費・住宅ローン・大型出費・積立・取り崩しまで途中式が列として並びます |
| 結果 | 主要指標（すべて「計算」シート参照の数式）、アドバイス、総資産の推移（データバー付き） |

INPUT シートの「収入の変化」表と「大型出費」表にはそれぞれ空行が 3 行用意してあり、Excel 上で行を書き足すだけで転職・育休や新しい出費を追加できます。大型出費は `SUMPRODUCT` と `MOD` で繰り返しを判定しています。値を書き換えると、計算シートと結果シートが Excel 側で再計算されます。数式は `INDEX`/`MATCH`/`PMT`/`SUMIFS`/`COUNTIFS`/`SUMPRODUCT` など Excel 2007 以降の標準関数のみを使用しています。

生成した数式は HyperFormula で評価し、アプリ内のシミュレーション結果と全セルが一致することを確認しています（差分 0）。

## 初期値の根拠

はじめに入っている値は、公的統計の平均・中央値に寄せています。

| 年収（本人／配偶者） | 520 万／380 万 | 国税庁「民間給与実態統計調査」の 30 代の平均 |
| 家賃 | 月 9 万円 | 民営借家の全国平均 5〜6 万円と首都圏 8〜10 万円の中間 |
| 大人の生活費 | 月 22 万円 | 総務省「家計調査」の消費支出から住居費・教育費・子どもの養育費を除いた大人 2 人分 |
| 現金／投資 | 300 万／100 万 | 金融広報中央委員会の調査による 30 代二人以上世帯の金融資産（中央値 200 万円台・平均 500 万円台） |

## 計算の前提

- 手取りは給与所得控除・社会保険料（約 14.7%）・所得税・住民税を差し引いた概算。扶養控除や配偶者控除は考慮していません
- 教育費は文部科学省「子供の学習費調査」などをもとにした年額の目安（公立小学校 34 万円、私立中学校 156 万円など）。**授業料・通学費・制服・給食費・塾や習い事の費用を含む学習費ベース**で、入学年には入学金（私立中 20 万円・私立高 15 万円・大学は公立 15 万円/私立 30 万円）を上乗せします
- 公立と私立の差は教育費テーブルで表現しているため、養育費（食費・衣類・医療費など）は進路によって変えていません。生活水準ごと変えたい場合は養育費も併せて調整してください
- 持ち家は元利均等返済。固定資産税・修繕費として物件価格の年 1.0%、購入時の諸費用として価格の 7% を計上
- 児童手当は 0〜2 歳が月 1.5 万円、3〜18 歳が月 1 万円、第 3 子以降は月 3 万円
- 退職後の生活費は現役期の 85%、年金は 65 歳から受給。インフレは考慮していません
- 生活費は「大人（本人・配偶者）の分」として入力し、そこにお子さん 1 人あたりの養育費を人数分そのまま加算します。子どもが増えれば生活費のベースもその分増えます
- 養育費は年齢帯ごとに設定でき（既定は 0〜2 歳 70 万円、3〜5 歳 75 万円、6〜11 歳 80 万円、12〜14 歳 90 万円、15〜17 歳 95 万円、18〜21 歳 100 万円。1 人あたり 0〜21 歳で約 1,870 万円）、最終学歴で決まる上限年齢を過ぎると 0 になります（高校卒なら 18 歳以降、大学院卒なら在学中も「18〜21 歳」の金額が続きます）。教育費・住居費はこれとは別に計算します
- 既定値は内閣府「子育て費用に関する調査」の年間子育て費用から、保育料・学校教育費・学校外教育費といった教育関連（本アプリでは教育費として別計上する分）を差し引き、近年の物価上昇を加味した目安です。18 歳以降に一人暮らしで仕送りをする場合は、18〜21 歳を 120〜150 万円に上げてください
- 児童手当の第 3 子加算は、21 歳以下の子の中での順位で判定します（年長の子が 22 歳になると順位が繰り上がります）
- 現金には預金金利、投資資産には想定利回りを別々に適用します
- 育児休業給付金は非課税・社会保険料免除のため、手取り＝給付額として計上します（休業前賃金の 67%→50%、プリセットでは約 60% で概算）

概算モデルのため、実際の家計判断には専門家への相談を併せてご検討ください。
